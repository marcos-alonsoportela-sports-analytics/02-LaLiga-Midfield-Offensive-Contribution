# LaLiga 2026-2026 Midfield Offensive Contribution

## Project Overview

This project analyses the offensive contribution of a sample of LaLiga midfielders during the 2025/26 season.

The objective was to compare players using offensive production and efficiency metrics and to develop a custom performance indicator called Offensive Score.

## Tools Used

- Python
- Pandas
- Google Colab
- Microsoft Excel
- Matplotlib

## Objectives

- Compare offensive performance between midfielders.
- Analyse production per 90 minutes.
- Develop a custom offensive metric.
- Visualise player performance.
